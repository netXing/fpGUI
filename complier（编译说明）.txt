编译 fpGUI2026.7.5 netXing1. 安装/编译 PasBuild 本身 bash git clone https://github.com/graemeg/PasBuild.git cd PasBuild mkdir -p target/units echo '1.0.0' > target/version.inc fpc -Mobjfpc -O1 -FEtarget -FUtarget/units -Fitarget \     -Fusrc/main/pascal src/main/pascal/PasBuild.pas2. 获取 fpGUI 源码 bash git clone https://github.com/graemeg/fpGUI.git cd fpGUI3. 安装 freetype bash brew install freetype4. 生成 fpc.cfg（解决库/单元搜索路径问题的根本方案） bash sudo fpcmkcfg -d BASEINSTALLDIR=/usr/local/lib/fpc/3.2.4 -o /usr/local/etc/fpc.cfg5. 补充 freetype 库搜索路径 bash echo '-Fl/usr/local/opt/freetype/lib' | sudo tee -a /usr/local/etc/fpc.cfg6. 批量加入所有 FPC 标准库（FCL）单元搜索路径一次性解决 XMLRead、URIParser 等一系列"找不到单元"的问题： bash for dir in /usr/local/lib/fpc/3.2.4/units/x86_64-darwin/*/; do   echo "-Fu${dir%/}" done | sudo tee -a /usr/local/etc/fpc.cfg7. 编译 fpGUI 框架 bash pasbuild compile -m fpgui-framework -p macos8.（可选）编译其他模块 bash pasbuild compile -m fpgui-docview -p macos       # DocView pasbuild compile -m fpgui-uidesigner -p macos    # UI Designer  9.运行编译好的fpgui-uidesigner，如果提示缺少字体则安装。brew install --cask font-liberation
